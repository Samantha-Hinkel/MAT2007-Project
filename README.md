# MAT2007-Project
Introduction to Programming Project - Snake Venoms

This project does the statistical analysis of a dataset dowloaded from Kaggle Venomous Snakes.csv. It looks into the distribution of snake venom toxicity across various species and questions whether there is a relationship between aggressive behaviour and venom toxicity.

What is needed to run this code:
- Python 3
- NumPy
- pandas
- Matplotlib

How to run the code:
1. Install Python in Visual Studio Code and the libraries mentioned above.
2. Place both Code-Project-Samantha-Hinkel.py and Venomous Snakes.csv into the same folder called "Project".
3. Run the script.

The files included here are:
- Code-Project-Samantha-Hinkel.py (the code itself)
- Venomous Snakes.csv (the dataset used for analysis)
- README.md (briefly explaining how to run the code)
